SCR_SubgradeFromFSL

  • this macro takes a given DTM and computes cross sections at intervals along the selected Alignment
  • it can drop those lines a chosen amount, and extend them until they intersect the DTM again
  • be careful where you choose the offset locations: between the two offsets the linework matches all grade changes of the DTM, afterwards it uses the DTM grade at the offset location to extrapolate until it hits the DTM



    TIP: drop it only a very small amount, i.e. 0.000001 m, use the builtin “Project cleanup” to connect the line segments, use SCR_LinePerpVertOffset to offset them perpendicular and create a new surface that is offset perpendicular to the source DTM; of course that will only work perfectly on dam like surfaces that run parallel to the alignment, with no side road tie-ins

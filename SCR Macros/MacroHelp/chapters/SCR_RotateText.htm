SCR_RotateText

  • tip: define a Shortcut for it i.e. “Ctrl + 3”
  • after running any of the Asbuilt reports you can use this macro to quickly rotate/shift selected Text around

  • added option to quickly change justification
  • small usage improvements:
    • if macro is started with text selected it will now immediately ask for the move origin (saves some clicking)
    • after rotating or changing the justification it also will ask for the move origin (saves some clicking)

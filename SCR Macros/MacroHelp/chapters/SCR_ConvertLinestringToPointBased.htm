SCR_ConvertLinestringToPointBased

  • the original goal of this macro was to convert lines from XY definition to point based with global coordinates; afterwards the projects coordinate system can be changed and the linework stays in place in the global context; hence transforming the linework to the new system as well, otherwise it would get shifted since TBC doesn’t transform the XY coordinates of linework during a system change
  • the point number will increment by 1 with each new point; if a point with that number exists already it will be incremented until it finds an unmatched one
  • works only for Linestrings
  • Alignments or 2DForeignCAD Polylines will need to be converted to “Linestrings” first
  • undefined Elevations in Linestrings will be assumed as 0.0, otherwise the conversion to global coordinates might fail
  • the Points get created on the source line’s layer
  • if “create new line” is checked those lines and points will be put on new layer(s) with suffix “ - Point-based”
  • added option to search for existing points - i.e. to verify that all linestrings are point-based before handing them over to TMR
  • can also check if the point code is the same as the line code, before adding it
    • if i.e. the line feature code is “FO”, the macro will match any point code that starts with “FO” and maybe a following number
    • it won’t match “FOE” or the like

SCR_AlignmentPlotFrames

  • create Plot Frames which are, in the Frame center, perpendicular to a selected Alignment
  • play around with the values and TBCUndo to check the Frame placing
  • once you are happy you can set the tick to create new sheets in an existing custom-type SheetSet and place the Dynaviews on them
  • can also be used in combination with SCR_QuickDynaToSheet

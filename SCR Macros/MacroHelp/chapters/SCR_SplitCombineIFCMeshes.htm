SCR_SplitCombineIFCMeshes

  • multiple ways to manipulate IFC objects and the BIM Entity tree in the Project Explorer
  • for a better understanding on how that tree works:
    • each entry in the BIM Entity tree can contain multiple so called ShellMeshInstances
    • those ShellMeshInstances, their number or settings aren't visible in the Project Explorer
    • a ShellMeshInstance is the visual representation setting for a so called ShellMeshData
    • the ShellMeshData contains the basic Mesh information of the object, the ShellMeshInstance the location, scaling, colour ... information
    • that means a ShellMeshData can be used over and over again, with different transformation information, without having to multiply the base data in the project
  • this macro is not meant to multiply and place IFC objects, but to manipulate/split/recombine existing definitions

  • depending on how a BIM Entity was defined in another program it can be that it only contains one single big MeshInstance, without any individual sub-meshes
  • in combination with SCR_ExplodeIFC you can now manually separate those and create new/smaller ones

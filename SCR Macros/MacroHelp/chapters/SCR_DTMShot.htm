SCR_DTMShot

  • similar to what TBC provides with “Surface Intersect”, but it doesn’t ask for angles, simply 2 points (i.e. snapped along a line)
  • can now also extend lines, just click near the end you want to extend
  • works now with projected surfaces and IFC objects



  • it's best to use "extend/trim" only if you know that the line is too short, OR the intersection will be on the last segment
    • otherwise it's better to use the new "break" option and manually delete the unwanted segments
    • in case the line is too long it could be that there are multiple segments after the intersection
    • in this case the trim will not work, because the intersection point is not on the last segment
  • added an option to break the line at all surface intersections; in this case it ignores the side of the line you clicked


  • added mode to use a user-defined plane
  • added mode to select multiple lines via rectangle/polygon selection; the lines are extended at the end where the selection crosses

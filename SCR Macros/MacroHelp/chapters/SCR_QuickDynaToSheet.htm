SCR_QuickDynaToSheet

  • if you have multiple Plot Frames with different orientations the TBCDynaview creator can be a pain
  • with this macro you can either select them one by one or bulk select them
  • with bulk selection it uses the internal entity serial number for sorting the frames, the internal serial number is always incrementing, means a frame that has been drawn later will be on a higher sheet number
  • it will create new Sheets in an existing SheetSet and place the Dynaviews accordingly
  • the “Easy” function assumes that the outlines start in the Bottom-Left
  • in a Clockwise outline it uses the last segment, in a CounterClockwise one the first segment to orientate it on the Sheet
  • can now add to existing Sheet; before it created a new sheet for every dynaview, now you can add multiple i.e. insets to the same sheet

SCR_CreateGeoRefWorldFiles

  • comes from a forum request
  • enables you to create the georeferenced worldfiles for multiple images/PDF at once, i.e. for use on the controller
  • just select the images/PDF in the Project Explorer and run the macro
  • since the images reside in the subfolder of the TBC project the worldfiles will be created there
  • there is also an option to copy the image and corresponding worldfile to a second folder
  • added conversion to JPG; Civillo can't import PNGs which are the result of referenced PDFs

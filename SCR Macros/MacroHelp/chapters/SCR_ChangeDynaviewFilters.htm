SCR_ChangeDynaviewFilters

  • select some Sheets in the Project Explorer and this macro can change the set Viewfilter of all Dynaviews on those Sheets
  • new option to change the SortRank of selected Sheets
  • the macro can achieve negative SortRankValues or greater than 100 which the properties pane doesn’t, that does work but I’m not 100% sure if it does not lead to any unwanted problems, better make sure to keep SortRanks between 0 and 100

SCR_PlaceObjects

  • place IFC Objects along a Linestring or at point locations
  • elevations can be retrieved from the object it is aligned to or from a surface



  • it is advisable to select the object in the BIM Tree instead the world view since that recreates the source’s full sub-tree



  • you can select the objects in the worldview, but in this case the new objects are created at the source’s location in the BIM tree


  • and beware, there is a weird bug in the project explorer; at least in my 2024.00; try to avoid doing the following
      • If you select/highlight something, but then for some reason collapse the tree so that the selection isn’t visible anymore it will disappear from the project explorer, don’t ask me why
      selected object
      but collapsed the part of the tree that contains that entity, so the highlighting is not visible anymore
      after running the macro there are only the copies visible
      all the data is still there, if you save the project and reload it’s all as it should be

SCR_ElevateSHPLines

  • will only work with V2024 or higher; it supports "Composite Geometry" and this was only introduced in V2024
  • linework from SHP-files is usually only 2D with the line elevation hidden in an attribute
  • find the attribute name, in the above example "Elevation", and type it into the search field of the macro
  • don't include the ":"
  • the macro creates new, elevated, linework

SCR_ChordLines

  • 12d handles horizontal arcs with a curved vertical profile as thousands of tiny little arcs
  • in TBC you can see that if you edit a linestring that originates from a 12d file


  • if you export those strings (multiple strings with 10thousands of arcs) to machine control it will run very slow, computation might be wrong because it is lagging behind and it might actually crash
  • this macro will approximate the arcs with polylines with a chosen accuracy

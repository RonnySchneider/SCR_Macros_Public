SCR_SimpleCADPoint

  • often a simple CADPoint is enough as construction point, no need to create named points all the time
  • you can still use all the right-click commands like BearingDistance etc.



  • option for QuickMidPoint might be handy on circular IFC objects


  • added option to create points along a line but picking elevation from offset points
    • if you have a thin spread scan and you want to use SCR_AnalyzeCloudAlongLine to create a best fit hog line
    • by creating those points directly on i.e. the CL it won't throw the best fit line of course if the scan points are arbitrarely spread around the CL
    • you probably want to pick points at nearly the same offsets left and right to average out an eventual cross fall in the cloud points

SCR_Check4DoubleSegments

  • Highlight Mode
    • the macro compares each segment of a linestring against all other segments in the whole project
    • this will be rather slow and naturally the user will need to decide wich line/segment to delete/break/fix

  • Delete Mode
    • the macro ignores all lines with more than 1 segment (2 points)
    • main use is to find and delete duplicate 2-point segments after exploding neighbouring IFC-BIM objects
    • is much faster than "Project-Cleanup" while still checking against separate horizontal/vertical tolerances
    • you can easily throw 100.000 or more lines on it, will only take a few seconds
    • 200.000 lines and above will naturally still take some time
    • currently it also doesn't check/compare segment types (curves etc.), it plainly looks at the start/end coordinates

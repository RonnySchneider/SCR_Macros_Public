SCR_3PtsToCircle

  • create a circle and its center from 3 points (CAD or named Points)
  • handy to check bolt blockouts
  • once you have the center point you can run the SCR_ABReportWithBearing to compare them to design



  • added option to create 3D circle
    • either use just the 3 points that define the circle as target plane; each circles plane potentially has a different orientation
    • or define a reference plane and the 3 circle points are projected onto it before the circle is computed
    • in the below example the circle points were selected in the point cloud but the circle computed on the blue plane


  • added mode for best-fit circles
    • with given or computed radius
    • on a 2D Z-average, 3D best-fit or user-defined plane
    • works with cloud points as well

SCR_ImportStaOffEl

  • create points based on chainages, elevations in a CSV file
  • the built-in functionality with "TBC Excel" at the start of the CSV file always needs actual RL’s, it doesn’t compute the alignment elevation
  • this macro can do either one, it can use RL’s or can compute the Alignments elevation on the given chainage and use that
  • added option to create dependent points

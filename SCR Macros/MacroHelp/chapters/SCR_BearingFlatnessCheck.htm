SCR_BearingFlatnessCheck

  • takes up to 9 points in a 3x3 pattern
  • 3 points will be used to define a 3DPlane; it works best to select those 3 points Bottom-Left -> Top-Left -> Top-Right
  • for the other points the perpendicular distance to that plane is computed and then used to compare them between pairs
  • for ease of use you can select all points, the macro checks it and ignores the 3 corner reference points

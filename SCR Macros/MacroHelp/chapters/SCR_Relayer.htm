SCR_Relayer

  • in Projects with a lot of layers it can be annoying to relayer objects via scrolling in the properties pane, usually you only have a handful of targetlayers
  • in this macro you can define a shortlist of layers which is saved in the project
  • you can do this by either double clicking in the top list
  • or highlight multiple layers with the held CTRL or SHIFT key and then click on the arrow down button
  • once you have some layers in the bottom list you only have to select some objects and doubleclick on a layer in the bottom list
  • the prefilter at the top can now be used with multiple space separated strings
  • ignore the checkboxes in the list, I don’t know yet how to disable them
